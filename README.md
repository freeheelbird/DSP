# DSP

Signal-processing study projects.

| Folder | What it is |
|---|---|
| [`polyphase_resampler/`](polyphase_resampler) | Polyphase rational resampler: interactive Python lab and browser app, SystemVerilog implementation, bit-exact fixed-point model, and an RTL-versus-model verification script. |
| [`filter/`](filter) | Lowpass filter designer: compares FIR and IIR types at the smallest size that meets one spec, with quantisation, multiplier counts, test input spectra and coefficient export. |
